CCJJLL630: Role
You are a software engineer responsible for implementing and testing the capabilities of AI models on the Regression subtype within the Bug-related category.
Your task is to provide two separate, complete Python projects:
Project A – Pre-Regression (Stable Implementation)
A project that contains the original, stable, and fully functional implementation of a user registration system. This version correctly validates user input, including email format, password requirements, and duplicate user checks.
Project B – Post-Regression (Buggy Implementation)
A project that contains a modified version of the same system after new feature updates (e.g., third-party login integration or enhanced password rules). This version introduces a regression bug — the email format validation logic has been broken, allowing invalid emails like "user@@mail" or "test@.com" to be accepted during registration.
Each project must include its own code, environment setup, test cases, and execution scripts.
You must ensure that all files are generated, stored locally, and fully reproducible.
Both projects should handle edge cases, performance considerations, and correctness verification while enabling measurable comparison of system reliability before and after regression.

Description
This experiment evaluates AI models’ ability to detect, reproduce, and diagnose regression bugs caused by unintended code changes.

•	Comprehensive automated test coverage for normal, edge, and invalid cases
•	Fully reproducible setup and one-click test execution
•	Quantitative comparison of test success rate, input coverage, and regression detection accuracy
